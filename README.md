Desenvolvimento de um jogo interativo de Pedra, Papel e Tesoura utilizando Python, com interação por meio do terminal e geração aleatória das escolhas do computador. O projeto permite que o usuário selecione entre pedra, papel ou tesoura, enquanto o sistema utiliza a biblioteca `random` para definir a jogada do oponente de forma automática. A lógica do jogo foi implementada por meio de estruturas condicionais responsáveis por identificar empates, vitórias e derrotas, além da criação de uma função específica para determinar o vencedor de cada rodada. O desenvolvimento também envolveu a utilização de funções, entrada e saída de dados, operadores lógicos e geração de valores aleatórios, com foco na aplicação prática dos fundamentos de programação e na construção de uma aplicação simples, interativa e funcional.
